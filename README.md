# Robert L.

**Founder and CTO at [QInformed](https://qinformed.com/). Founder and CEO at [Binary Shadow](https://bshadow.us/).**

I work where protocols, operating systems, infrastructure and trust boundaries meet.

My work runs from packet behavior and process internals to security architecture and production operations.

## // Selected Public Work

### [VT7](https://github.com/TheBinaryShadow/VT7)

A substantial effort to bring a modern terminal experience to Windows 7. VT7 builds on Microsoft's open-source Terminal components and adapts the rendering, session and transport layers for an older operating system. Local shells and direct SSH have been tested on physical Windows 7 machines. **VT7 is pre-alpha and has no public release yet.**

### [VT7Pty](https://github.com/TheBinaryShadow/vt7pty)

A separate user-mode console backend derived from WinPTY. The project is building toward more faithful console I/O, predictable process lifetimes and a stronger foundation for VT7. **VT7Pty is in early development.**

### [Quantum Entanglement Engine](https://bshadow.us/qee.html)

Binary Shadow's encrypted origin-to-edge transport platform. It connects protected infrastructure to Binary Shadow's edge without opening public inbound ports at the origin. The linked overview is the public description of the project.

## // Engineering Approach

I start with the behavior below the product boundary: packets, protocol state, process lifetimes, I/O paths and trust assumptions. I test what the system actually does, then build upward toward reliable tools and infrastructure.

My professional work spans commercial systems and high-assurance environments. Much of it has no public artifact. What is here is the part I can show.
